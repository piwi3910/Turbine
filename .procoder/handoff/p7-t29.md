## What the harness does

`gdn_eval [all|decode|prefill|conv]` uses the Qwen3.5-9B shapes (16 key heads × 128, 32 value heads × 128, conv k=4
over 8192 channels, F32 state). It checks every candidate against an F64 host recurrence (the transformers
`torch_recurrent_gated_delta_rule` math, q and k pre-L2-normalized, BF16-representable inputs, non-zero initial state)
and prints the median µs over 50 runs (10 to 20 at T = 16384):

- **GDN decode B = 1, 16, 64:** llama.cpp `gated_delta_net_cuda`, extracted verbatim from `ggml-cuda/gated_delta_net.cu`
  and compiled through `shim/ggml_shim.h`. It is F32 in and out, wave32, and also prints the achieved state GB/s
  against the 640 GB/s peak. AITER has no HIP GDN decode kernel: its decode is Triton (`fused_recurrent`), so it does
  not apply.
- **GDN prefill T = 100 (correctness only, tail chunk), 128, 2048, 16384:**
  - (a) the llama.cpp recurrence. It is token-sequential, has no chunked kernel ("TODO: Add chunked kernel" in the
    source) and maps heads tiled (`h % 16`). The reference handles that mapping.
  - (b) the FLA chunked pipeline. The chunk-state stage is AITER `chunk_gated_delta_rule_fwd_h_hip_kernel` (gfx12
    wave64 WMMA, BF16 k/w/u, F32 state, BF16 snapshots, `-mwavefrontsize64`). `chunk_h_launcher.inc` launches one
    instantiation and bypasses AITER's 1,536-instantiation dispatch, which compiles for longer than 10 minutes.
    AITER implements the other stages only in Triton/FlyDSL, so they are Turbine prototypes: `own_prep` (chunk cumsum,
    kkt, in-place (I+A)^-1, w/u) and `own_o`. Both are scalar FP32 in LDS and not optimized. The pipeline runs for
    bv = 16, 32 and 64, and `*` marks AITER's own bv rule. Each run prints the per-stage µs.
- **conv decode B = 1, 16, 64 and prefill T = 128, 2048, 16384:**
  - llama.cpp `ssm_conv_f32` / `_long_token` (F32). Its input is channel-major with the state concatenated. In
    llama.cpp's graph that is an extra transpose and concat pass, which is not timed; note it.
  - AITER `causal_conv1d_update` (decode, BF16).
  - AITER `causal_conv1d_fwd_split_qkv_hip` (prefill, BF16, channel-last input, fused q/k/v split, updates the conv
    state).
