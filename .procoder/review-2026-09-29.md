## Provisional decisions (pending user review)

Full options in `.procoder/ask/decisions.md`, entry "Phase 6a/6b builder decisions, provisional (2026-09-29)". One line each:

- YaRN test tolerance: 2 FP32 ulps instead of the spec's 1e-7 (below FP32 resolution); alternative: mimic transformers' FP32 order (still 1 ulp off in 4/256).
- YaRN extends context only when `original < max_position_embeddings` (spec edge case); alternative: always up to `factor × original`.
- YaRN refuses factor < 1, attention factor ≤ 0, `beta_slow` > `beta_fast`; transformers only warns.
- YaRN defaults follow Python's `or`; unknown keys ignored.
- `rope_identity` includes `rotary_dim`.
- FP8 KV: F8E4M3 paged `dtype` means FP8 pages with BF16 Q/new rows/output; CPU FP8-KV row `experimental`.
- 6b TurboQuant QJL: Gaussian projection S per (layer, head) instead of the plan's second Hadamard (which was biased by ~2.7 %); costs O(d²) and ~15–17 MB of S tables on the GPU; alternatives: one S per namespace, or loosen unbiasedness.
- 6b: `turbine-kv` keeps its own e4m3 rounding copy (tested bit-exact) instead of moving it to `turbine-core`.
- 6b `KvCodec` interface details (layout argument, per-layer scales, extra helpers).
- 6b FP8 codec from BF16: per block per layer K/V scales in a slot header.
- 6b TurboQuant layout: 16-byte-padded records (tq4 3.56×, tq2 6.4× vs BF16; unpadded 3.82× / 7.3×).
- 6b TurboQuant rounding, seeds, codebook construction and NMSE bounds (details in decisions.md).
- 6b ladder rule details (no action at GREEN, lowest tier first, one rung at a time, floor evicts).
- 6b ladder reason codes join the metric label sets only with 6b Task 15.
- Mixed-format L0 (6b) uses one page class per format carved from the KV budget (flagged at the spec answers).
- FP8 (Task 8): `quant_method: fp8` per-tensor with dynamic activations runs per-token activation scales (vLLM: dynamic per tensor); alternative: add that mode to the ABI.
